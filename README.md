## 🌐 Cara Publikasi Gratis ke Internet

Untuk membagikan tautan portofolio ini ke rekruter atau mencantumkannya di profil LinkedIn:

### Opsi 1: GitHub Pages (Gratis & Cepat)
1. Buat repositori baru di GitHub dengan nama `muhammad-roihan-portfolio`.
2. Unggah seluruh isi folder ini (`index.html`, `styles.css`, `script.js`, dan folder `assets/`).
3. Buka **Settings** > **Pages** > pilih branch `main` lalu klik **Save**.
4. Website akan aktif dalam beberapa menit di alamat: `https://username.github.io/muhammad-roihan-portfolio/`.

### Opsi 2: Vercel / Netlify (Drag & Drop)
1. Buka [vercel.com](https://vercel.com) atau [netlify.com](https://netlify.com).
2. Tarik dan lepas (*drag and drop*) folder `muhammad-roihan-portfolio` ke dasbor.
3. Website akan langsung aktif dengan domain gratis seperti `muhammad-roihan.vercel.app`.
